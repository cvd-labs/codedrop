    On any other site, CodeDrop's toolbar icon gets an orange dot when the page shows a code box. Click it and choose Turn on.

    Which emails are trusted

    A code is offered on a site only if Gmail confirms the email really came from the same company as that site (DMARC or DKIM pass). For example, a code from noreply@github.com is offered on github.com, never on a lookalike site.
